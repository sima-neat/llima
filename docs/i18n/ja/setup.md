# システム要件

GenAIモデルのコンパイルとデプロイには、Model Compilerを使用してください。これは、Neat開発環境に付属しています。ホストまたはNeat Frameworkアプリケーションも構築する場合は、完全なNeat開発環境が必要になります。

Model Compilerは、以下の要件を満たすマシンにインストールする必要があります。

| パラメータ | 説明 |
|----|----|
| **オペレーティングシステム** | Ubuntu 22.04/24.04 LTS、またはWindows 11、またはMacOS 12.0以降。 |
| **メモリ** | 128GB以上を推奨します。 |
| **保存** | 512GBの空き容量があると望ましい。 |

:::note
128GBのコンピューターを使用した場合、コンパイルにかかる時間は、モデルの種類によって異なり、数時間かかる場合があります。64GBのコンピューターであれば、画像処理機能を必要としないモデルであれば使用できる可能性があります。
:::

## 前提条件

- 最新の[、`sima-cli`、](/tools/sima-cli/)がModel Compilerにインストールされていることを確認してください。
- SDK環境に必要なSiMa.aiのリリースアセットにアクセスできるようにしてください。
- オープンソースのモデルをダウンロードするには、有効な Hugging Face アカウントが必要です。
- 一部のモデル（例：`google/paligemma`）では、Hugging Faceでライセンス契約に同意する必要があります。これらのモデルをダウンロードする前に、ライセンスの内容を確認し、同意するようにしてください。
- CLIに、[ユーザーアクセストークン](https://huggingface.co/docs/hub/en/security-tokens)と`huggingface-cli`を使用して、Hugging Faceへのアクセスを許可します。`sima-cli`をインストールすると、`huggingface-cli`も自動的にインストールされます。

### CI の sysroot 選択

`deps/manifest.json` はファームウェアの対象 `3.0.0_master_B2372` を選択し、CI は
対応する master の sysroot リビジョン `3.0.0~pre2372` を解決します。
`3.0.0~git202610140145.e5ece50-2121` などの develop リビジョンにも対応しています。
`sdk.channel` は SDK ツールチェーンイメージを選択し、プラットフォームのビルドチャネルとは独立しています。

CI は使い捨ての SDK コンテナーで `scripts/ci/prepare_sysroot.sh` を呼び出します。
準備前に、共有リゾルバーの出力がファームウェア宣言と一致することを検証します。
master 3.0 のリビジョンは、アーカイブのチェックサムで検証された SDK コミット
`2c325eeb1f0e4551ac32f2b9ef53a4cc18a07ccf` の SDK 管理トランザクション型インストーラーを使い、
pre-release Agate リポジトリから準備します。現在の SDK 開発用ヘルパーは master リビジョンに
対応していますが、廃止済みの `appcomplex-dev` パッケージも要求するため、CI ヘルパーは
固定したインストーラーからその要求だけを削除します。SDK のパッケージ選択が修正されたら、
この一時的な互換性処理を削除してください。元の SDK イメージの記録は保持され、適用中の
オーバーレイとパッケージ一覧が選択した正確な sysroot を記録します。その一覧に解決した
正確なプラットフォームバージョンがない場合、準備は失敗します。

このヘルパーは使い捨ての CI コンテナー専用で、使用中の開発環境向けではありません。
LLiMa は引き続きプラットフォームライブラリを直接使い、Internals パッケージには依存しません。
この sysroot でビルドしても DevKit の動作検証やファームウェア更新にはなりません。
